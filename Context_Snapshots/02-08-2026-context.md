# Bilagun Web Project - Context Snapshot
**Date:** 02-08-2026

## 1. Current Project State & Completed Milestones
- **React Migration Complete:** The old React application was completely removed and replaced with a high-performance static architecture (HTML, CSS, Vanilla JS).
- **Database Architecture:** Created `dogs_database.json` as the single source of truth. Successfully populated it by scraping 11 profiles from the Pedigree Database (extracting Sire, Dam, Birth Date, Titles).
- **Assets Mapping:** Successfully mapped all optimized `.webp` images to their respective dogs in the JSON database.
- **Level 1 (Grid):** Implemented a dynamic grid system that only renders dogs containing valid photos. The first photo acts as the primary thumbnail.
- **Level 2 (Immersive Profile):** Rebuilt the individual dog page (`dog.html`) into a premium 100vh immersive layout. Features include a full-screen background image, a cinematic gradient overlay, absolute-positioned information, and a custom fade-transition slider for navigating galleries of multiple photos per dog.

## 2. Active Architectural Decisions
- **Stack:** Pure HTML / CSS / Vanilla JS. No heavy frameworks (React/Next) to keep the project lightweight and fast.
- **Routing:** Implemented **hash-based routing** (`dog.html#id` instead of `?id=`) for Level 2 profiles. This prevents local static servers (like `serve`) from stripping out query parameters during "clean URL" redirects.
- **Gallery Engine:** Custom-built vanilla JS slider relying on CSS `opacity` transitions for smooth image swapping without third-party dependencies.
- **Design Philosophy:** Premium, strict, and immersive (resembling a high-end showcase). Emphasizes large imagery and clean typography (Montserrat).

## 3. Next Immediate Steps

- **Contact Form:** The form currently uses a simple `mailto:` action. Needs to be connected to a proper backend or form service (e.g., Formspree, Firebase, or PHP script) if direct email delivery is required.
